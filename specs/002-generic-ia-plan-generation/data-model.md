# Data Model: Generic Training Plan Generation with AI

**Feature**: 002-generic-ia-plan-generation  
**Date**: 2026-06-24

---

## No New Tables or Columns

This feature introduces no new database tables and no new columns. All persistence changes are behavioral: the `source` field on existing records is now assigned correctly based on which generation path was used.

---

## Affected Entity: `TrainingPlan` (train schema)

| Field | Type | Current Behavior | New Behavior |
|-------|------|-----------------|--------------|
| `source` | `VARCHAR(20)` | Always `"ai"` for generic plans (bug) | `"ai"` when IA generation succeeds; `"template"` for rule-based and clone plans |
| `profile_hash` | `VARCHAR(64)` | Populated on all generated plans | Unchanged |
| `original_plan_id` | `UUID` | Set on clones only | Unchanged |

### `source` field semantics (corrected)

| Value | Meaning |
|-------|---------|
| `"ai"` | Plan was generated in full by the external IA API in this request |
| `"template"` | Plan was generated by the rule-based engine (either from the start, or as fallback after IA failure), OR is a clone of another plan |
| `"coach"` | Manually created by a coach (existing; unchanged) |

### Paths that write each `source` value

```
POST /plans/generate  (plan_type=generic)
  ├── Reuse path (clone_plan)                  → source="template"  ← FIXED (was: copied from source)
  ├── New plan, no generic_ia feature           → source="template"  ← FIXED (was: "ai")
  ├── New plan, generic_ia + IA fails           → source="template"  ← FIXED (was: "ai")
  └── New plan, generic_ia + IA succeeds        → source="ai"        ← NEW (first time this is real)

POST /plans/generate  (plan_type=adaptive)
  └── Unchanged                                 → source="ai"
```

---

## Affected Entity: `TrainingSession` (train schema)

| Field | Type | Current Behavior | New Behavior |
|-------|------|-----------------|--------------|
| `source` | `VARCHAR(20)` | Always `"ai"` for generic sessions (bug) | `"ai"` when parent plan is AI-generated; `"template"` otherwise |

Session `source` mirrors the plan `source` for all sessions created in the same `generate_generic_plan()` call. A single `source` variable is resolved once and applied to all sessions created in the loop.

---

## Unaffected Entities

The following entities are read but not structurally modified:

- `AthleteProfile` — read to get `profile_id`
- `AthleteSportProfileValue` — read to build `profile_data`
- `AthleteGoalValue` — read for `goal_target_date` → `duration_weeks`
- `AthleteTrainingStructureValue` — read for `days_per_week`
- `TrainingPlanPhase` — created as today (unchanged structure)
- `TrainingPlanSession` — join record (unchanged structure)
- `TrainingSessionBlock` — created from IA or rule-based workout data (unchanged structure)

---

## No Alembic Migration Required

All columns used by this feature already exist in the `train` schema. The only change is behavioral assignment of values within existing columns.
